# Journal: Rich Text vs. Markdown Mode

The Journal editor defaults to a **rich text (WYSIWYG)** experience — bold, italic, headings (up to five levels), lists, links, images, code blocks, and colored callout boxes (Note / Tip / Warning), all with no markdown syntax to remember.

## Switching to Markdown
Use the **Rich / Markdown / Split / Preview** tabs in the editor toolbar:
- **Rich** — the default WYSIWYG surface.
- **Markdown** — edit the raw markdown source directly.
- **Split** — markdown source and a live rendered preview side by side (stacks vertically on phones).
- **Preview** — a read-only rendered view.

Entries are stored as plain markdown under the hood either way, so switching modes never loses formatting.

## Embedding media
Journal entries are a **link library, not storage** — BJJ Mind Map never uploads or hosts your pictures or videos. Paste any link via the toolbar's **Embed media** button:
- A direct image link renders as an image.
- A YouTube or Vimeo link renders as an embedded player.
- A direct video file link (.mp4, .webm, etc.) renders as a native video player.
- Any other link renders as a clickable "View source" card.

## Exporting
- Use the **Print / PDF** button in any entry to print or save it as a PDF.
- From your Profile page, use **Export journal to Markdown** to download every entry across all notebooks as a `.zip` of plain `.md` files.
